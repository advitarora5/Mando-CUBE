# Database setup

1. Copy `.env.example` to `.env.local` and configure the server-only secret key locally.
2. Run `supabase/migrations/202610020001_initial_schema.sql` once in Supabase SQL Editor.
3. Restart the dev server. A connected empty database shows zero records.

CLI alternative:

```bash
npx supabase init
npx supabase login
npx supabase link --project-ref fkhychihxpregusklggo
npx supabase db push
```

Review remote state before pushing. If you used SQL Editor, reconcile CLI migration history before future pushes rather than reapplying the same SQL.

## Tables

- companies: stable identity, size, industry, headquarters, signal date, source.
- contacts: company-linked buyer contacts and sources.
- scores: dated assessments, five category values, five evidence strings. Evidence format: `https://source | one-line reason`. Total is generated by Postgres; tier will be computed by the scoring engine.
- company_insights: generated fields and separate manual overrides.
- weekly_snapshots: saved ranks, score reference and frozen insights. Foreign keys ensure the score belongs to the same company.

Append new score rows; never update a row referenced by history. Immutable database enforcement will be added with the history implementation.
